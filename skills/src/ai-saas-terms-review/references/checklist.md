# AI/SaaS Terms Review Checklist

## 1. 基本情報

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| 対象サービス | サービス名、提供会社、契約主体、サービス概要 | 高 |
| 対象文書 | Terms、Privacy Policy、Usage Policy、DPA、SLA、Security、Subprocessor list | 高 |
| 更新日 | Effective date / Last updated / 確認日 | 高 |
| プラン差 | Free / Pro / Team / Enterpriseでデータ利用条件が違うか | 中 |

## 2. サービス構造とデータ流通

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| サービス類型 | 単体SaaS、AI生成、外部LLM連携、AIオーケストレーション、RAG、エージェント型 | 高 |
| データ流通 | 入力、出力、アップロード、ログ、メタデータがどの事業者を通るか | 高 |
| 外部送信 | 外部LLM、クラウド、分析、監視、決済、サポート等に渡るか | 高 |
| ルーティング | モデル・プロバイダーの自動選択、固定、除外が可能か | 高 |

## 3. 収集データと利用目的

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| アカウント情報 | 氏名、メール、会社名、アカウントID、請求情報 | 中 |
| サービス操作データ | プロンプト、ファイル、コード、画像、出力、フィードバック | 高 |
| 技術データ | IP、端末ID、OS、ブラウザ、クラッシュログ、診断ログ | 中 |
| サポートデータ | 問い合わせ、チケット、添付資料、通信内容 | 中 |
| 利用目的 | サービス提供、保守、セキュリティ、請求、法令遵守、改善、学習、マーケティング | 高 |

## 4. 学習利用・改善利用

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| 学習利用 | 入力・出力がモデル学習、再学習、ファインチューニングに使われるか | 高 |
| 評価・改善 | 評価、品質改善、分析、機能開発に使われるか | 高 |
| デフォルト | 学習利用がデフォルトオンかオフか | 高 |
| オプトアウト | 管理画面、申請、契約で無効化できるか | 高 |
| 組織制御 | Organization / Workspace単位で強制できるか | 高 |
| 過去データ | オプトアウト前データ、学習済みモデル、派生データを削除・取消できるか | 高 |
| 外部LLM反映 | 自社側オプトアウトが外部LLM側にも適用されるか | 高 |
| 人間レビュー | 人が入力・出力を見る条件、停止可否、委託先レビューの有無 | 中〜高 |

## 5. 外部LLM・サブプロセッサ

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| LLM一覧 | 使用されるプロバイダー・モデル一覧 | 高 |
| 限定性 | 記載ベンダーが限定列挙か例示か | 高 |
| 除外制御 | 特定モデル・特定ベンダーを除外できるか | 高 |
| 外部保持 | 外部LLM側の入力・出力・ログ・キャッシュ保持期間 | 高 |
| 外部削除 | 削除依頼、契約終了時に外部側でどこまで削除されるか | 高 |
| サブプロセッサ | 再委託先一覧、処理内容、処理国、変更通知、拒否権 | 高 |

## 6. データ処理国・保存国・国外転送

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| データ処理国 | 入力、出力、ファイル、ログ、メタデータが処理される国 | 高 |
| データ保存国 | 顧客データ、ログ、バックアップの保存国・クラウドリージョン | 高 |
| 外部LLM側処理国 | 外部モデルプロバイダー側の処理国・保存国 | 高 |
| サポート閲覧国 | サポート担当・委託先がどの国から閲覧できるか | 中 |
| 国内固定 | 日本国内処理・保存、特定リージョン固定、国外転送なしが可能か | 中〜高 |
| 国外移転根拠 | SCC、十分性認定、同意、DPA、データ移転契約等 | 中〜高 |

## 7. DPA・契約条件

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| DPA有無 | Data Processing Agreement / Addendumを締結できるか | 高 |
| 立場 | Controller / Processor、委託元 / 委託先の整理 | 高 |
| 処理対象 | DPAの対象データに入力・出力・ログ・ファイルが含まれるか | 高 |
| 処理目的 | サービス提供と学習・改善が分離されているか | 高 |
| 再委託 | サブプロセッサ条項、変更通知、異議申立て、解約権 | 高 |
| 国外移転 | 移転先国、移転根拠、SCC等 | 高 |
| 削除・返却 | 契約終了時の返却・削除、バックアップ削除 | 高 |
| 監査 | 監査権、第三者監査報告書、セキュリティ資料提供 | 中〜高 |
| 事故通知 | 漏えい・不正アクセス時の通知期限と方法 | 高 |
| 非学習条件 | DPAまたは個別契約で顧客データの非学習を明記できるか | 高 |

## 8. 保持期間・削除範囲

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| 保持期間 | データ種別ごとの保持日数 | 高 |
| 削除対象 | 入力、出力、ファイル、ログ、メタデータ、サポート情報 | 高 |
| 削除対象外 | 監査ログ、法令保存、バックアップ、キャッシュ、学習済みモデル | 高 |
| 契約終了時 | 退会・契約終了後の削除期限 | 高 |
| バックアップ | バックアップからの削除反映タイミング | 中〜高 |

## 9. セキュリティ・監査・認証

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| 第三者認証 | SOC 2 Type II、ISO27001、ISMAP、PCI-DSS等 | 中〜高 |
| 暗号化 | 通信時・保存時暗号化、鍵管理、顧客管理鍵 | 高 |
| アクセス制御 | 従業員アクセス、最小権限、MFA、特権管理 | 高 |
| 監査ログ | 管理者操作、データアクセス、API利用ログ | 中〜高 |
| 脆弱性管理 | 脆弱性診断、ペネトレーションテスト、バグバウンティ | 中 |
| インシデント対応 | 通知期限、対応体制、事後報告 | 高 |

## 10. 権利・生成物・ライセンス

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| 入力の権利 | ユーザーが入力データの権利を保持するか | 高 |
| 出力の権利 | 出力の権利帰属、商用利用可否 | 高 |
| 利用許諾 | 事業者へのライセンス範囲、再許諾、譲渡、永続性 | 高 |
| マーケティング | 顧客名、事例、入力・出力を宣伝に使われないか | 中 |
| 知財侵害 | 出力が第三者権利を侵害した場合の責任分界 | 中 |

## 11. Usage Policy・禁止用途

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| 違法・危険行為 | 違法行為、危険物、犯罪支援の禁止 | 中 |
| セキュリティ用途 | コード解析、脆弱性診断、ペンテスト、検証が許容されるか | 高 |
| 個人情報分析 | 同意なし取得、プロファイリング、センシティブ推定の禁止 | 高 |
| 高リスク判断 | 法務、医療、金融、人事、教育、公共、保険等での自動判断制限 | 高 |
| 顧客対応 | 出力を顧客向け回答にそのまま使えるか、人間確認が必要か | 中〜高 |

## 12. SLA・責任分界

| 項目 | 確認内容 | 優先度 |
| --- | --- | --- |
| SLA | 稼働率、障害対応、返金・クレジット | 中 |
| 責任上限 | 損害賠償上限、除外損害 | 中 |
| 補償義務 | ユーザー側補償、ベンダー側補償、知財補償 | 中 |
| 出力保証なし | 正確性、完全性、最新性、適法性の免責 | 中 |
| 規約変更 | 変更通知、拒否権、解約権 | 中 |
