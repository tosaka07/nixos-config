# Vendor Questions

## 最優先: 導入可否に直結する項目

1. 入力、出力、アップロードファイル、ログ、メタデータはモデル学習、再学習、ファインチューニング、評価、品質改善に利用されますか。
2. 学習利用はデフォルトで有効ですか。組織単位でデフォルト無効にできますか。
3. 学習利用オプトアウトは、外部LLMプロバイダー側の学習・改善利用にも適用されますか。
4. 利用される外部LLMプロバイダーおよびモデル一覧を開示できますか。
5. モデル・プロバイダーを固定、除外、制限できますか。
6. 入力、出力、ログ、一時キャッシュは外部LLM側で保持されますか。保持される場合、期間は何日ですか。
7. 削除依頼時・契約終了時に、外部LLM側・サブプロセッサ側のデータはどこまで削除されますか。
8. データ処理国、保存国、バックアップ保存国、外部LLM側の処理国を開示できますか。
9. 日本国内処理・日本国内保存、または特定リージョン固定は可能ですか。
10. DPAを締結できますか。DPAに再委託、国外移転、削除・返却、監査、事故通知、非学習条件は含まれますか。
11. 全サブプロセッサ一覧、処理内容、処理国、変更通知、異議申立て、解約権を提供できますか。

## 次点: セキュリティ・法務審査で必要な項目

1. SOC 2 Type II、ISO27001、ISMAP等の第三者認証を取得していますか。報告書を提供できますか。
2. 脆弱性診断、ペネトレーションテスト、セキュリティ監査結果を提出できますか。
3. 通信時・保存時暗号化、鍵管理、顧客管理鍵の対応状況を説明できますか。
4. 従業員または委託先が顧客データへアクセスする条件、承認フロー、監査ログを説明できますか。
5. 管理者操作ログ、API利用ログ、データアクセスログの保存期間と顧客への提供可否を説明できますか。
6. インシデント発生時の通知期限、通知方法、報告内容を説明できますか。
7. SLA、稼働率保証、障害時サポート、返金・サービスクレジットを提供できますか。
8. Enterprise契約で、責任上限、補償条項、目的外利用禁止、非学習条件を個別交渉できますか。

## 用途次第で確認する項目

1. コード解析、脆弱性調査、セキュリティ検証用途はUsage Policy上許容されますか。事前承認は必要ですか。
2. 顧客データ、個人情報、機密情報を含む入力は契約上許容されますか。
3. 法務、医療、金融、人事、保険、教育、公共サービス等の高リスク領域での利用条件は何ですか。
4. 出力結果を顧客向け回答、契約書、仕様書、設計書、社外公開文書に利用する場合の条件は何ですか。
5. 出力結果の商用利用、著作権、知財侵害時の責任分界、補償はどうなりますか。
6. 入力・出力・顧客名・利用事例がマーケティングや事例紹介に使われる可能性はありますか。拒否できますか。
